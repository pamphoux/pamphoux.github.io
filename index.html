Réseau & Sécurité 🔒 En Production

Accès distant sécurisé pour bases de données Sage 100 SQL

Défi : Permettre à des clients distants d'interroger en temps réel les tables SQL Server d'un ERP Sage Ligne 100, sans jamais exposer le port 1433 publiquement sur Internet.

Solution mise en œuvre :
  • Création d'un service (daemon) automatisant un tunnel SSH inverse (Remote Tunneling).
  • Déploiement d'un VPS bastion faisant office de passerelle pivot sécurisée avec filtrage Pare-feu (iptables).
  • Durcissement de la sécurité via une authentification exclusive par clés Ed25519 avec passphrase.
  • Intégration de ssh-agent pour la gestion sécurisée et persistante des clés en mémoire.
  • Tunnel SSH Forward côté client pour interroger la base distante de manière fluide.
SSH Ed25519 ssh-agent SQL Server iptables
RDBMS & Maintenance 🛠️ Expertise

Datafix de masse & Restauration d'intégrité de données

Défi : Intervenir en urgence ou lors de maintenances sur des bases de données de production corrompues (bugs applicatifs, ruptures d'intégrité) sans provoquer d'interruption prolongée.

Méthodologie & Rigueur :
  • Politique Safety First : Backup à chaud systématique et validation réelle de la restauration sur environnement de staging.
  • Conception de requêtes d'écriture massives (UPDATE / MERGE par lots/batches) limitant le verrouillage des tables.
  • Nettoyage, normalisation et reconstruction des contraintes d'intégrité sous MariaDB et SQL Server.
  • Création systématique de scripts de rollback validés avant bascule en production.
APIs & E-Commerce Integration ⚙️ Automatisation

Passerelles d'interconnexion & Synchronisation de flux ERP / E-Commerce

Défi : Automatiser les échanges de données financiers et logistiques entre des plateformes de vente (OpenCart, osCommerce) et les outils de gestion/comptabilité moderne (Pennylane, écosystème Sage), sans double saisie humaine.

Solution mise en œuvre :
  • Développement de scripts d'automatisation en Python pour l'extraction et le traitement des données brutes.
  • Modélisation, prototypage et validation des requêtes de flux via Postman.
  • Déploiement de pipelines d'import/export de données exploitant les pilotes ODBC pour lier le web aux bases de données locales.
  • Planification et monitoring des tâches de synchronisation asynchrones via des tâches Crontab Linux hautement disponibles.
Hypervisors & Infrastructure ⚡ Optimisation

Architecture Cloud Privé & Cluster de Virtualisation KVM / Proxmox

Défi : Rationaliser un parc de serveurs physiques sous-exploités en migrant vers une infrastructure virtuelle agile, hautement disponible et sans surcoût de licence propriétaire.

Solution mise en œuvre :
  • Déploiement et administration d'un cluster Proxmox VE avec stockage partagé.
  • Configuration d'instances virtuelles haute performance basées sur KVM / qemu / libvirt pour une isolation native et un overhead minimal.
  • Conteneurisation d'applications micro-services via Docker pour fluidifier les environnements de test et de staging.
  • Mise en place d'une supervision centralisée avec Zabbix (alerting CPU, RAM, IOPS) pour anticiper les goulots d'étranglement.
